# Rover model sources

The imported rover models are NASA 3D Resources downloads. Their source pages credit NASA and the originating NASA center. The Sojourner rover is a clearly labeled research-informed reconstruction built for this scene because the NASA model library did not contain a downloadable Sojourner rover mesh.

- Spirit and Opportunity: [NASA/JPL-Caltech Mars Exploration Rovers](https://science.nasa.gov/resource/mars-exploration-rovers-3d-model/). One twin rover mesh is used for each of the physically near-identical MER vehicles; the mission labels and landing sites remain distinct.
- Curiosity: [NASA/JPL-Caltech Curiosity Rover 3D model](https://science.nasa.gov/resource/curiosity-rover-3d-model/).
- Perseverance: [NASA/JPL Mars 2020 Perseverance model](https://science.nasa.gov/3d-resources/mars-2020-perseverance-rover/).
- Sojourner reconstruction reference: [NASA Pathfinder rover overview](https://science.nasa.gov/mission/pathfinder/).

NASA models were downloaded in October 2026. Preserve these attributions when redistributing the Unity project. NASA's usage guidance is at [NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
